✅ PASO 1: Ejecutar Migración (OBLIGATORIO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  php artisan migrate
  
  Esto creará la tabla 'product_files' en tu base de datos.


✅ PASO 2: Probar en Admin
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Ir a: Admin → Productos
  2. Seleccionar un producto
  3. Debería ver opción para "Subir Archivo"
  4. Probar subiendo un ZIP o archivo pequeño


✅ PASO 3: Integrar en tu Vista (Página del Producto)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  En tu blade template donde muestres detalles del producto, agrega:
  
  <x-product-files :product="$product" :showStats="true" />
  
  Esto automáticamente mostrará todos los archivos descargables.


✅ PASO 4: Probar Descarga
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Como usuario logueado, intenta descargar un archivo
  2. Verifica que se incremente el contador de descargas
  3. Revisa que el archivo tenga el nombre original

P: ¿Dónde se guardan los archivos?
R: storage/app/games/products/{product_id}/{uuid}.ext

P: ¿Cuál es el tamaño máximo?
R: 10GB (configurable)

P: ¿Cómo se protegen?
R: No están en public/, solo accesibles vía /download/game/{id}

P: ¿Quién puede descargar?
R: Admin, producto gratuito, o usuario que compró

P: ¿Se incrementa automáticamente el contador?
R: Sí, cada descarga incrementa el contador
